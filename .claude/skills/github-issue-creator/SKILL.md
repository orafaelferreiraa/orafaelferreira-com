# GitHub Issue Creator

Use this skill when raw notes, logs, or screenshots need to become a structured issue.

## Output shape

- Summary
- Environment
- Reproduction steps
- Expected behavior
- Actual behavior
- Error details
- Impact

## Rules

- Be concise.
- Preserve the facts.
- Mark unknowns explicitly.
