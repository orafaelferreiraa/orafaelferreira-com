# MCP Builder

Use this skill when designing or reviewing an MCP server.

## Principles

- Prefer clear, action-oriented tool names.
- Keep outputs small and structured.
- Make errors actionable.
- Document exactly what each tool can do.

## Workflow

1. Confirm whether an existing Microsoft server already covers the need.
2. Define the smallest useful tool set.
3. Validate tool naming, schemas, and result shape.
4. Test the server with real agent-style usage.
